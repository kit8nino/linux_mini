# Шпаргалка:

### [БЛОК 1. УСТРОЙСТВО Linux и BASH]

*   **Ядро (Kernel)** — прослойка между железом и софтом. Управляет ресурсами.
*   **Shell (оболочка)** — интерпретатор команд. Bash — самая популярная. Это ваш язык общения с ядром.
*   **Всё — файл**: устройства (`/dev`), процессы (`/proc`), диски, логи. Если не можете починить — перезагрузитесь, если не помогло — читайте логи.
*   **Права доступа** (`rwx`). Запомните: `chmod 755` — стандарт для скриптов, `600` — для ключей SSH.

---

### [БЛОК 2. НАВИГАЦИЯ]

Эти команды вы будете вбивать вслепую 100 раз в день.

*   `pwd` — Где я?
*   `ls -la` — Что тут есть? (Обязательно с `-la`, чтобы видеть скрытые файлы и права).
*   `cd -` — Вернуться в предыдущую директорию (экономит кучу времени).
*   `history` | `grep "что-то"` — Найти команду, которую вводил вчера.
    *   *Совет:* `Ctrl + R` (reverse search) — начинает поиск по истории. Жмите и печатайте кусок команды.
*   `tree` — Визуально посмотреть структуру папок (если не установлен — `apt install tree`).
*   `du -sh *` | `sort -hr` — Найти папки, которые сожрали всё место на диске.

### [БЛОК 3. РАБОТА С ТЕКСТОМ (СВЯТОЕ)]

В Linux всё строится на тексте. Научитесь жонглировать строками.

*   `cat`, `less`, `head`, `tail -f` — просмотр логов. `-f` (follow) — живые логи, незаменимо.
*   `grep` — главный инструмент.
    *   `grep -rin "error" /var/log/` — рекурсивно, игнорируя регистр, с номерами строк.
    *   `grep -A5 -B5 "panic" app.log` — показать 5 строк ДО и ПОСЛЕ совпадения.
*   `awk` — работа с колонками. (Показываю минимум):
    *   `ps aux | awk '{print $2, $11}'` — вывести PID и имя команды всех процессов.
*   `sed` — замена текста на лету (без открытия редактора):
    *   `sed -i 's/старый_IP/новый_IP/g' config.conf` — заменить IP во всем файле.
*   **Конвейер (`|`)** — основа основ. Выход одной команды — вход для другой.
    *   *Пример:* `cat access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10` — Топ-10 IP-адресов, долбящих ваш сервер.

### [БЛОК 4. ПРОЦЕССЫ И УПРАВЛЕНИЕ]

*   `ps auxf` — дерево процессов. `ps aux | grep python` — найти свой скрипт.
*   `top` / `htop` — диспетчер задач. Научитесь убивать процессы по PID: `kill -9 [PID]` (беспощадный), `kill -15` (вежливый).
*   `nohup ./my_script.sh &` — запустить скрипт в фоне, чтобы не сдох при закрытии терминала (лучше использовать `screen` или `tmux`, но это отдельная тема).
*   `netstat -tulpn` или `ss -tulpn` — посмотреть, какие порты слушает сервер.

### [БЛОК 5. ПИШЕМ СКРИПТЫ]

Скрипт — это последовательность команд в файле. **Важно**: Первая строка — `#!/bin/bash` (шебанг).

#### 5.1. Переменные и арифметика
```bash
#!/bin/bash
NAME="Стажер"
NOW=$(date +%Y-%m-%d)  # Подстановка результата команды в переменную
echo "Привет, $NAME. Сегодня $NOW"
COUNT=$(ls -1 | wc -l)
echo "Файлов в папке: $COUNT"
```

#### 5.2. Условные операторы (if)
*Проверяем, существует ли файл, чтобы случайно не перезаписать его.*
```bash
if [ -f "backup.tar.gz" ]; then
    echo "Ошибка: файл уже существует!" >&2  # >&2 — вывод в stderr
    exit 1
else
    tar -czf backup.tar.gz ./data/
    echo "Бэкап создан"
fi
```
*   `-f` — файл, `-d` — директория, `-z` — пустая ли строка.

#### 5.3. Циклы (for)
*Идеально для массовых операций.*
```bash
# Переименовать все .jpg в .jpeg
for file in *.jpg; do
    mv "$file" "${file%.jpg}.jpeg"  # Хитрость с удалением суффикса
    echo "Переименован: $file"
done
```

#### 5.4. Функции
```bash
function log() {
    echo "[$(date '+%H:%M:%S')] $1" >> /var/log/my_app.log
}
log "Скрипт запущен"
```

### [БЛОК 6. ПРАКТИЧЕСКОЕ ЗАДАНИЕ (Собираем всё вместе)]

**Задача:** Написать скрипт мониторинга, который проверяет, жив ли процесс по имени, и если нет — перезапускает его, пишет в лог.

*Показываю готовый вариант, стажёры печатают:*
```bash
#!/bin/bash

APP_NAME="nginx"
LOG="/var/log/monitor.log"

if pgrep -x "$APP_NAME" > /dev/null; then
    echo "$(date) - $APP_NAME работает" >> $LOG
else
    echo "$(date) - ВНИМАНИЕ! $APP_NAME упал. Перезапускаю..." >> $LOG
    systemctl restart $APP_NAME  # Или просто /etc/init.d/nginx start
fi
```
*Добавляем в cron (`crontab -e`):*
`*/5 * * * * /home/user/monitor.sh` — запуск каждые 5 минут.

### БЛОК 7. КАК ЭТО ИСПОЛЬЗОВАТЬ В ПОВСЕДНЕВКЕ (Советы)

1.  **Алиасы (псевдонимы)**. Не печатайте длинные команды. Создайте `~/.bashrc`:
    *   `alias ll='ls -lah'`
    *   `alias ..='cd ..'`
    *   `alias gs='git status'`
    *   После редактирования: `source ~/.bashrc`.
2.  **История**. Не копипастите пароли в историю. Ставьте пробел перед командой с паролем — она не сохранится.
3.  **Man pages**. Не знаете флаг — `man command` или `command --help`.
4.  **Проверка синтаксиса**. Перед запуском сложного скрипта: `bash -n script.sh` (просто проверит, нет ли ошибок), и `bash -x script.sh` (выполнит с отладкой — покажет каждую команду).
5.  **Права**. После написания скрипта: `chmod +x script.sh`. Теперь его можно запускать как `. /script.sh`.
