
**Midnight Commander (`mc`)** — двухпанельный консольный файловый менеджер с текстовым интерфейсом, вдохновлённый легендарным Norton Commander. Незаменим на серверах по SSH, где нет графической оболочки: позволяет копировать, перемещать, просматривать и редактировать файлы, а также перемещаться по каталогам без длинных цепочек `cd`, `ls`, `cp`.

---
## 1. Установка и запуск

**Установка:**
```bash
# Debian/Ubuntu
sudo apt install mc

# RHEL/CentOS/AlmaLinux
sudo dnf install mc
```


**Запуск:**
```bash
mc                  # Запуск файлового менеджера
mcedit filename     # Запуск встроенного редактора и открытие файла
```


**Выход:** `F10`

---
## 2. Интерфейс

Экран `mc` делится на несколько зон:

- **Верхняя строка** — основное меню (появляется по `F9`).
- **Центральная часть** — левая и правая панели с содержимым каталогов. Одна из них — **текущая** (активная).
- **Вторая строка снизу** — командная строка (можно вводить команды оболочки).
- **Нижняя строка** — подсказка с назначением функциональных клавиш `F1`–`F10`.

---
## 3. Основные операции (F-клавиши)

| Клавиша | Действие |
| :--- | :--- |
| `F1` | Справка |
| `F2` | Пользовательское меню |
| `F3` | Просмотр файла |
| `F4` | Редактирование файла |
| `F5` | Копирование (в папку неактивной панели) |
| `F6` | Перемещение / переименование |
| `F7` | Создать каталог |
| `F8` | Удаление |
| `F9` | Верхнее меню |
| `F10` | Выход |

> **Если F-клавиши не работают** (перехватываются терминалом или `tmux`), используйте эмуляцию: `Esc` + цифра (например, `Esc` + `5` вместо `F5`).

---
## 4. Навигация и панели

| Клавиша | Действие |
| :--- | :--- |
| `Tab` | Переключение между панелями |
| `↑` / `↓` | Перемещение по списку файлов |
| `Enter` | Открыть папку / запустить исполняемый файл |
| `Ctrl` + `O` | Скрыть/показать панели (показать вывод терминала) |
| `Ctrl` + `R` | Перечитать содержимое каталога |
| `Alt` + `.` | Показать/скрыть скрытые файлы (начинающиеся с точки) |
| `Alt` + `I` | Сделать текущим каталог неактивной панели |
| `Alt` + `O` | Неактивная панель переходит в каталог активной |
| `Ctrl` + `\` | Быстрый переход в каталог (список избранных каталогов) |

---
## 5. Работа с файлами

| Клавиша | Действие |
| :--- | :--- |
| `Insert` | Отметить (выделить) файл для групповых операций |
| `+` (на цифровой клавиатуре) | Выделить группу по маске (например, `*.txt`) |
| `\` (на цифровой клавиатуре) | Снять выделение с группы |
| `*` (на цифровой клавиатуре) | Инвертировать выделение |
| `Shift` + `F4` | Создать новый файл |
| `Shift` + `F6` | Переименовать файл «на месте» |
| `Ctrl` + `Space` | Показать размер текущего каталога |

---
## 6. Командная строка (в mc)

| Клавиша | Действие |
| :--- | :--- |
| `Alt` + `Enter` | Вставить имя файла/каталога под курсором в командную строку |
| `Alt` + `A` | Вставить полный путь активной панели |
| `Alt` + `P` | Вернуть предыдущую выполненную команду |
| `Alt` + `N` | Следующая команда в истории |
| `Ctrl` + `X`, `T` | Вставить все выделенные объекты в командную строку |
| `Ctrl` + `X`, `P` | Вставить полный путь активной панели |

---
## 7. Поиск

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl` + `S` | Быстрый поиск файла/каталога в текущей панели |
| `Alt` + `Shift` + `?` | Расширенный поиск (по содержимому, размеру, дате и т.д.) |

---
## 8. Права доступа и ссылки

| Клавиша | Действие |
| :--- | :--- |
| `Ctrl` + `X`, `O` | Изменить владельца/группу |
| `Ctrl` + `X`, `C` | Изменить права доступа (chmod) |
| `Ctrl` + `X`, `L` | Создать жёсткую ссылку |
| `Ctrl` + `X`, `S` | Создать символическую ссылку |

---
## 9. Встроенный редактор (`mcedit`)

`mc` имеет встроенный текстовый редактор `mcedit` с подсветкой синтаксиса и поддержкой мыши.

- **Запуск:** `F4` (открыть файл) или `Shift` + `F4` (создать новый).
- **Выход с сохранением:** `F2` (сохранить), затем `F10` (выйти).
- **Выделение текста:** `Shift` + `←`/`→`/`↑`/`↓`。
- **Копировать/вставить:** `Ctrl` + `Insert` (копировать), `Shift` + `Insert` (вставить).
- **Вырезать:** `Shift` + `Delete`。
- **Отмена:** `Ctrl` + `U`。
- **Меню редактора:** `F9`.

> **Смена редактора по умолчанию:** Если вы привыкли к `vim` или `nano`, в меню `Настройки → Конфигурация` снимите галочку «Использовать внутренний редактор», либо задайте переменную `EDITOR` перед запуском: `EDITOR=vim mc`.

---
## 10. Поддержка мыши

`mc` поддерживает управление мышью (если терминал позволяет):

- **Левая кнопка** — выбрать файл.
- **Правая кнопка** — отметить/снять отметку.
- **Двойной щелчок** — открыть файл/папку.
- **Клик на функциональных клавишах** в нижней строке — выполнить команду.

---
## 11. Шпаргалка (самое частое)

```bash
# Запуск
mc                      # Запустить файловый менеджер
mcedit file.txt         # Открыть файл во встроенном редакторе

# Навигация
Tab                     # Переключить панель
Ctrl+O                  # Спрятать панели (показать терминал)
Alt+.                   # Показать скрытые файлы

# Операции с файлами
F5                      # Копировать
F6                      # Переместить/переименовать
F7                      # Создать папку
F8                      # Удалить
Insert                  # Отметить файл для групповой операции

# Просмотр и редактирование
F3                      # Просмотреть файл
F4                      # Редактировать файл
Shift+F4                # Создать новый файл

# Поиск
Ctrl+S                  # Быстрый поиск
Alt+Shift+?             # Расширенный поиск

# Выход
F10                     # Выйти из mc
```

## 12. Дополнительные возможности

- **Виртуальные файловые системы (VFS):** `mc` умеет «заходить» внутрь архивов (`tar.gz`, `zip`), RPM-пакетов и даже на FTP/SFTP-серверы (в зависимости от сборки).
- **Фоновые операции:** `Ctrl` + `X`, `J` — показать фоновые задания (копирование/перемещение в фоне).
- **История каталогов:** `Alt` + `H` — просмотр последних посещённых каталогов.
- **Пользовательское меню:** `F2` — можно настроить свои команды для быстрого доступа.

---

`mc` — это швейцарский нож для работы в терминале. Освойте основные клавиши — и работа на сервере станет в разы быстрее и комфортнее.
