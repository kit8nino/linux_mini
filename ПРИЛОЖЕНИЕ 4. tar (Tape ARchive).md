
`tar` — это стандартный инструмент для создания и распаковки архивов в Linux. Изначально он работал с магнитными лентами, но сейчас используется для упаковки файлов в один архивный файл (`.tar`) и часто в сочетании со сжатием (`.tar.gz`, `.tar.bz2`, `.tar.xz`, `.tar.zst`). Это незаменимая команда для бэкапов, переноса проектов, дистрибутивов и логов.

---
## 1. Базовый синтаксис

```bash
tar [опции] [архив] [файлы/папки]
```

**Важное правило:** опции могут быть с `-` или без него (например, `tar -xzf` и `tar xzf` работают одинаково, но с `-` читается лучше). Обычно используют компактный стиль без `-` для быстрых команд.

---
## 2. Основные операции (режимы)

| Опция | Действие |
| :--- | :--- |
| `-c` (--create) | Создать новый архив. |
| `-x` (--extract) | Извлечь файлы из архива. |
| `-t` (--list) | Показать содержимое архива (без распаковки). |
| `-r` (--append) | Добавить файлы в конец существующего архива. |
| `-u` (--update) | Обновить архив (добавить только те файлы, которые новее, чем в архиве). |
| `-d` (--diff) | Сравнить архив с файловой системой (показать различия). |
| `-A` (--concatenate) | Объединить два архива. |

---
## 3. Основные опции (флаги)

| Опция | Действие |
| :--- | :--- |
| `-f` (--file) | Указывает имя архива (обязательно, если работаем с файлом). |
| `-v` (--verbose) | Выводить список обрабатываемых файлов. |
| `-z` (--gzip) | Использовать сжатие через `gzip` (расширение `.gz`). |
| `-j` (--bzip2) | Использовать сжатие через `bzip2` (расширение `.bz2`). |
| `-J` (--xz) | Использовать сжатие через `xz` (расширение `.xz`). |
| `--zstd` | Использовать сжатие через `zstd` (расширение `.zst`). |
| `-p` (--preserve-permissions) | Сохранять права доступа файлов (важно для бэкапов). |
| `-P` (--absolute-names) | Не удалять ведущий слеш из путей (опасно при распаковке!). |
| `-C` (--directory) | Сменить директорию перед выполнением операции (важно для распаковки в конкретную папку). |
| `--exclude=шаблон` | Исключить файлы по шаблону. |
| `--delete` | Удалить файл из архива (не поддерживается для сжатых архивов). |
| `-T` (--files-from) | Прочитать список файлов из файла. |
| `-X` (--exclude-from) | Исключить файлы по списку из файла. |

---
## 4. Синтаксис сжатия (современный стиль)

Хотя классический синтаксис использует `-z`, `-j`, `-J`, современный `tar` автоматически определяет тип сжатия по расширению, поэтому можно писать просто `-a` (auto) или опускать флаг сжатия:

```bash
tar -caf archive.tar.gz /path/to/folder   # -a автоматом выберет сжатие по .gz
```

Но для совместимости и явности лучше использовать явные флаги.

---
## 5. Самые частые операции (примеры)

### 5.1. Создание архива

**Простой .tar (без сжатия):**
```bash
tar -cvf archive.tar /home/user/project
```

**Сжатый .tar.gz (gzip):**
```bash
tar -czvf archive.tar.gz /home/user/project
```

**Сжатый .tar.bz2 (bzip2, лучше сжимает, но медленнее):**
```bash
tar -cjvf archive.tar.bz2 /home/user/project
```

**Сжатый .tar.xz (лучшее сжатие, медленный):**
```bash
tar -cJvf archive.tar.xz /home/user/project
```

**Исключая файлы и папки:**
```bash
tar -czvf archive.tar.gz /home/user/project --exclude=*.log --exclude=cache/
```

**Исключая по списку из файла:**
```bash
tar -czvf archive.tar.gz /home/user/project -X exclude-list.txt
```

**Архивация с сохранением прав и владельцев (для бэкапов):**
```bash
tar -czpvf backup.tar.gz /etc /var/log
```

**Архивация из списка файлов:**
```bash
find . -name "*.log" -type f | tar -czvf logs.tar.gz -T -
```

### 5.2. Распаковка (извлечение)

**Распаковать в текущую папку:**
```bash
tar -xvf archive.tar.gz
```

**Распаковать в конкретную папку (создаст, если нет):**
```bash
tar -xvf archive.tar.gz -C /target/dir
```

**Распаковать только конкретный файл/папку:**
```bash
tar -xvf archive.tar.gz project/README.md
```

**Распаковать с сохранением прав:**
```bash
tar -xvpvf archive.tar.gz
```

**Распаковать с автоматическим определением сжатия:**
```bash
tar -xaf archive.tar.gz   # -a = auto (определяет по расширению)
```

### 5.3. Просмотр содержимого

**Посмотреть список файлов в архиве:**
```bash
tar -tvf archive.tar.gz
```

**Подробно с размерами:**
```bash
tar -tvf archive.tar.gz | less
```

### 5.4. Добавление файлов в существующий архив (только для .tar, не сжатых!)

```bash
tar -rvf archive.tar newfile.txt
```
**Важно:** Нельзя добавлять файлы в сжатый архив (.tar.gz) — нужно создать новый или распаковать и перепаковать.

### 5.5. Удаление файлов из архива (только .tar, не сжатый)

```bash
tar --delete -f archive.tar file_to_delete
```

### 5.6. Сравнение архива с файловой системой

```bash
tar -df archive.tar /path/to/current/folder
```
Покажет, какие файлы изменились или отсутствуют.

## 6. Шпаргалка (самое частое)

```bash
# Создать архив .tar.gz
tar -czvf archive.tar.gz /path/to/folder

# Распаковать .tar.gz
tar -xzvf archive.tar.gz

# Распаковать в другую папку
tar -xzvf archive.tar.gz -C /target/dir

# Посмотреть содержимое
tar -tvf archive.tar.gz

# Создать архив, исключив .log файлы
tar -czvf archive.tar.gz /path --exclude=*.log

# Создать архив с сохранением прав
tar -czpvf backup.tar.gz /etc /home/user

# Распаковать с правами
tar -xvpvf backup.tar.gz

# Создать архив из списка файлов (например, find)
find /var/log -name "*.log" | tar -czvf logs.tar.gz -T -

# Создать .tar.bz2 (лучше сжатие)
tar -cjvf archive.tar.bz2 /path

# Создать .tar.xz (ещё лучше сжатие, медленно)
tar -cJvf archive.tar.xz /path

# Распаковать с автоматическим определением типа сжатия
tar -xaf archive.tar.gz   # или .bz2, .xz

# Извлечь один файл
tar -xvf archive.tar.gz project/file.txt
```

---
## 7. Полезные нюансы

- **Пути в архиве:** По умолчанию `tar` сохраняет пути относительно корня команды. Если вы архивируете `/home/user/project`, внутри архива будет `home/user/project/...`. Чтобы убрать лишние уровни, перейдите в нужную папку:  
  `cd /home/user && tar -czvf project.tar.gz project` (тогда внутри будет `project/...`).

- **Относительные пути:** Часто используют `tar -czf archive.tar.gz -C /home/user project` — тогда внутри архива папка `project` без полного пути.

- **Символические ссылки:** `tar` сохраняет ссылки как ссылки (по умолчанию), а не как файлы.

- **Большие архивы:** Для бэкапов на терабайты используйте `tar` с `--checkpoint` для индикации прогресса и `--verify` для проверки целостности.

- **Распаковка с заменой:** При распаковке `tar` перезаписывает существующие файлы без предупреждения. Используйте `--keep-old-files` или `--skip-old-files`, если нужно избежать перезаписи.

- **Сжатие на лету:** Если у вас большой каталог, используйте `tar -czf - . | ssh user@host 'cat > backup.tar.gz'` — сжатие и передача по сети без промежуточного файла.

---
## 8. Сравнение методов сжатия

| Метод | Расширение | Флаг | Скорость | Степень сжатия | Применение |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Без сжатия | `.tar` | `-cvf` | Мгновенно | Нет | Для промежуточных архивов |
| `gzip` | `.tar.gz` или `.tgz` | `-z` | Быстро | Средняя | По умолчанию, универсальный |
| `bzip2` | `.tar.bz2` | `-j` | Медленнее | Лучше, чем gzip | Для бэкапов, не критичных к времени |
| `xz` | `.tar.xz` | `-J` | Медленно | Очень хорошая | Для максимального сжатия (например, дистрибутивы) |
| `zstd` | `.tar.zst` | `--zstd` | Очень быстро | Между gzip и xz | Новый стандарт, быстро и хорошо сжимает |

---

`tar` — это базовая, но мощная утилита, которую вы будете использовать ежедневно. Освойте эти примеры, и вы всегда сможете создавать бэкапы, переносить проекты и распаковывать чужие архивы без проблем.
