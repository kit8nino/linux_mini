
**`awk`** — мощный язык обработки структурированных текстовых данных. Он читает входные данные (файлы или STDIN) построчно, разбивает строки на поля (по умолчанию по пробелам), и позволяет выполнять действия над ними. Идеален для работы с отчетами, логами, CSV, извлечения колонок, агрегации и фильтрации.

---
## 1. Базовый синтаксис

```bash
awk 'program' [файл...]
awk 'pattern { action }' [файл...]
```

- `program` — последовательность команд.
- Шаблон `pattern` (условие) — если строка удовлетворяет условию, выполняется `action`.
- Если `pattern` опущен, `action` применяется ко всем строкам.
- Если `action` опущен, по умолчанию выполняется `{ print }`.

**Примеры:**
```bash
# Вывести все строки файла (действие по умолчанию)
awk '{ print }' file.txt

# Вывести все строки, где 3-е поле > 100
awk '$3 > 100' data.txt

# Вывести второе поле каждой строки
awk '{ print $2 }' file.txt
```

---
## 2. Структура программы и как она работает

`awk` обрабатывает входные данные построчно. В каждой строке:
1. Проверяет все условия (`pattern`).
2. Если условие истинно, выполняет соответствующий `action`.
3. Если условие ложно, действие пропускается.

**Синтаксис правил:**  
`pattern1 { action1 } pattern2 { action2 } ...`

**Специальные блоки:**
- `BEGIN { ... }` — выполняется один раз **до** чтения первого файла (инициализация).
- `END { ... }` — выполняется один раз **после** обработки всех строк (подведение итогов).

**Пример:**
```bash
awk 'BEGIN { print "Начинаем..." } { print $1 } END { print "Конец" }' file.txt
```

---
## 3. Встроенные переменные (самые важные)

| Переменная | Описание |
| :--- | :--- |
| `$0` | Вся текущая строка (целиком). |
| `$1`, `$2`, ... | Отдельные поля (столбцы). |
| `NF` | Number of Fields — количество полей в текущей строке. |
| `NR` | Number of Records — номер текущей строки (глобальный счётчик). |
| `FNR` | File Number of Records — номер строки в текущем файле (сбрасывается для каждого файла). |
| `FILENAME` | Имя текущего обрабатываемого файла. |
| `FS` | Field Separator — разделитель полей (по умолчанию пробел). |
| `OFS` | Output Field Separator — разделитель при выводе полей (по умолчанию пробел). |
| `RS` | Record Separator — разделитель записей (по умолчанию перевод строки). |
| `ORS` | Output Record Separator (по умолчанию перевод строки). |
| `ARGC`, `ARGV` | Аргументы командной строки. |

**Примеры:**
```bash
# Вывести номер строки и первое поле
awk '{ print NR, $1 }' file.txt

# Вывести количество полей в строке
awk '{ print NF }' file.txt

# Изменить разделитель полей на двоеточие
awk -F: '{ print $1 }' /etc/passwd
```

---
## 4. Работа с полями

**Вывод нескольких полей:**
```bash
awk '{ print $2, $5 }' file.txt
```

**Перестановка и форматирование:**
```bash
# Поменять местами поля 1 и 3
awk '{ print $3, $2, $1 }' file.txt

# С разделителем запятая на выходе
awk -v OFS=',' '{ print $1, $2 }' file.txt
```

**Условная печать полей:**
```bash
# Если 3-е поле больше 100, вывести 1-е и 3-е
awk '$3 > 100 { print $1, $3 }' data.txt
```

## 5. Типовые `pattern` (условия)

- **По номеру строки:** `NR == 5`, `NR > 10`, `NR == FNR` (для сравнения файлов).
- **По содержимому поля:** `$2 == "error"`, `$3 ~ /regex/`, `$4 !~ /debug/`.
- **Логические операции:** `&&`, `||`, `!`.
- **Сравнение чисел:** `$5 > 100`, `$5 >= 50`.

**Примеры:**
```bash
# Строки, где 2-е поле начинается с "A"
awk '$2 ~ /^A/' file.txt

# Исключить строки с 3-м полем = 0
awk '$3 != 0' file.txt

# Строки с 5 по 10
awk 'NR >= 5 && NR <= 10' file.txt
```

---
## 6. Действия (`action`) и управляющие конструкции

### Печать и форматирование:
- `print` — выводит с разделителем `OFS` и завершает `ORS`.
- `printf` — форматированный вывод (как в C).

```bash
# Форматированный вывод: %s — строка, %d — число, \n — перевод
awk '{ printf "%-10s %5d\n", $1, $2 }' file.txt
```

### Условный оператор `if`:
```bash
awk '{ if ($3 > 100) print $1; else print "Маловато" }' file.txt
```

### Циклы `for`, `while`:
```bash
# Сумма всех полей в каждой строке
awk '{ sum = 0; for (i=1; i<=NF; i++) sum += $i; print sum }' file.txt
```

### Пропуск дальнейшей обработки строки:
```bash
# Пропустить строки, где 1-е поле пустое
awk '$1 == "" { next } { print }' file.txt
```

## 7. Арифметика и встроенные функции

### Арифметические операции:
`+`, `-`, `*`, `/`, `%`, `^` (возведение в степень).

### Математические функции (стандартные):
`sin(x)`, `cos(x)`, `sqrt(x)`, `log(x)`, `exp(x)`, `int(x)` (целая часть).

### Строковые функции:
- `length([строка])` — длина строки.
- `substr(строка, начало, длина)` — извлечение подстроки.
- `index(строка, подстрока)` — позиция подстроки.
- `split(строка, массив, разделитель)` — разбиение строки в массив.
- `toupper(строка)`, `tolower(строка)` — регистр.
- `match(строка, регулярка)` — возвращает позицию совпадения.
- `sub(рег, замена, строка)` — замена первого совпадения.
- `gsub(рег, замена, строка)` — замена всех совпадений.

**Примеры:**
```bash
# Вывести длину каждого поля
awk '{ for (i=1; i<=NF; i++) print length($i) }' file.txt

# Преобразовать все имена в верхний регистр
awk '{ print toupper($0) }' file.txt
```

## 8. Массивы (ассоциативные)

В `awk` массивы индексируются строками (не только числами). Позволяют считать частоты, группировать данные.

```bash
# Подсчёт вхождений IP-адресов
awk '{ count[$1]++ } END { for (ip in count) print ip, count[ip] }' access.log
```

**Удаление элемента:** `delete array[key]`.
**Проверка существования:** `if (key in array)`.

---
## 9. BEGIN и END блоки

- `BEGIN` — инициализация переменных, заголовков, разделителей.
- `END` — вывод итоговых данных (сумм, средних).

**Пример: сумма чисел в 3-м поле:**
```bash
awk 'BEGIN { sum = 0 } { sum += $3 } END { print "Итого:", sum }' data.txt
```

## 10. Практические однострочники (самые частые задачи)

#### 10.1. Вывести определённый столбец (например, IP из лога)
```bash
awk '{ print $1 }' access.log
```
### 10.2. Под#считать количество строк (заменяет `wc -l`)
```bash
awk 'END { print NR }' file.txt
```
#### 10.3. Вывести строки с номерами (как `cat -n`)
```bash
awk '{ print NR, $0 }' file.txt
```
#### 10.4. Сумма чисел в столбце
```bash
awk '{ sum += $2 } END { print sum }' data.txt
```
#### 10.5. Среднее арифметическое по столбцу
```bash
awk '{ sum += $2 } END { print sum / NR }' data.txt
```
#### 10.6. Удалить дубликаты по первому полю (печатать только первое вхождение)
```bash
awk '!seen[$1]++' file.txt
```
#### 10.7. Сортировка по второму полю (числовому)
```bash
awk '{ print $2, $1 }' file.txt | sort -n | awk '{ print $2, $1 }'
```
(Это пример, для сложной сортировки лучше использовать `sort -k`.)
#### 10.8. Вывести строки, где длина поля > 10
```bash
awk 'length($1) > 10' file.txt
```
#### 10.9. Разбить CSV с разделителем `,` и вывести 1-й и 3-й столбцы
```bash
awk -F, '{ print $1, $3 }' data.csv
```
#### 10.10. Найти максимум в столбце
```bash
awk 'NR == 1 { max = $2 } $2 > max { max = $2 } END { print max }' data.txt
```

## 11. Работа с несколькими файлами

`awk` обрабатывает файлы последовательно. Переменная `FNR` сбрасывается при переходе на новый файл, а `NR` — глобальный.

**Пример: сравнение двух файлов по первому полю:**
```bash
awk 'NR == FNR { a[$1] = $2; next } $1 in a { print $1, a[$1], $2 }' file1 file2
```

```bash
awk -v threshold=100 '$2 > threshold { print $1 }' data.txt
```

## 13. Отличия от `sed` и `grep`

| Утилита | Основное применение |
| :--- | :--- |
| `grep` | Поиск/фильтрация строк по шаблону. |
| `sed` | Потоковое редактирование: замена, удаление, вставка. |
| `awk` | Обработка структурированных данных (поля, агрегация, вычисления). |

- `awk` более мощный для работы с колонками и вычислениями.
- `sed` быстрее для простых замен.
- `grep` — самый простой для фильтрации.

---
## 14. Частые ошибки и советы

- **Не забывайте кавычки:** Программа `awk` всегда в одинарных кавычках, чтобы оболочка не интерпретировала `$`.
- **Использование `-F` для разделителя:** Если разделитель — несколько символов, используйте регулярное выражение: `-F'[ ,]+'`.
- **Порядок `BEGIN` и `END`:** `BEGIN` — до данных, `END` — после.
- **Избегайте лишних `print`:** Если не указать действие, `awk` выводит всю строку.
- **Работа с большими файлами:** `awk` очень эффективен, но массивы могут потреблять память.

## 15. Шпаргалка (самое частое)

```bash
# Вывести 2-й столбец
awk '{ print $2 }' file.txt

# Сумма 3-го столбца
awk '{ sum += $3 } END { print sum }' file.txt

# Строки, где 1-й столбец начинается с "a"
awk '$1 ~ /^a/' file.txt

# Подсчёт уникальных значений в 1-м столбце
awk '{ count[$1]++ } END { for (i in count) print i, count[i] }' file.txt

# Преобразовать дату (формат 2023-12-25 -> 25/12/2023)
awk -F- '{ print $3 "/" $2 "/" $1 }' file.txt

# Вывести строки, у которых количество полей > 3
awk 'NF > 3' file.txt

# Вывести последнее поле каждой строки
awk '{ print $NF }' file.txt

# Заменить все запятые на табуляции
awk -F, -v OFS='\t' '{ $1=$1; print }' file.csv
```
