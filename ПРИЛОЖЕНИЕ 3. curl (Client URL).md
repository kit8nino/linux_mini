
`curl` — это мощная утилита командной строки для передачи данных по множеству протоколов: HTTP, HTTPS, FTP, SFTP, SMTP и другие. Это незаменимый инструмент для тестирования API, скачивания файлов, отправки данных на сервер и отладки сетевых взаимодействий.

---
## 1. Базовый синтаксис

```bash
curl [опции] URL
```

- По умолчанию `curl` выполняет GET-запрос и выводит ответ сервера в STDOUT.

---
## 2. Основные опции (самые частые)

| Опция | Действие |
| :--- | :--- |
| `-o файл` | Сохранить вывод в файл (как `wget`). |
| `-O` | Сохранить с именем, взятым из URL (последний сегмент). |
| `-L` | Следовать за редиректами (Location). |
| `-i` | Показывать заголовки ответа вместе с телом. |
| `-I` | Получить только заголовки HEAD. |
| `-v` | Подробный вывод (debug-режим) — показывает заголовки запроса и ответа. |
| `-s` | Тихий режим (без прогресс-бара и ошибок). |
| `-H "Заголовок: значение"` | Добавить произвольный заголовок. |
| `-X МЕТОД` | Указать метод HTTP (GET, POST, PUT, DELETE). |
| `-d "данные"` | Отправить данные в теле запроса (метод POST). |
| `-F "поле=значение"` | Отправить форму или файл (multipart/form-data). |
| `-u пользователь:пароль` | Базовая HTTP-аутентификация. |
| `-k` | Игнорировать проверку SSL-сертификата (небезопасно!). |
| `-b файл` | Отправить cookies из файла (или строка). |
| `-c файл` | Сохранить cookies в файл. |
| `--limit-rate` | Ограничить скорость. |
| `-C -` | Продолжить докачку файла (с поддержкой возобновления). |
| `--max-time` | Максимальное время выполнения. |
| `--retry` | Количество повторных попыток при ошибке. |

---
## 3. Базовые примеры

**Простой GET-запрос:**
```bash
curl https://api.example.com/users
```

**Сохранить файл с оригинальным именем:**
```bash
curl -O https://example.com/file.zip
```

**Сохранить с другим именем:**
```bash
curl -o archive.zip https://example.com/file.zip
```

**Получить заголовки ответа:**
```bash
curl -I https://example.com
```

**Следовать за редиректами и показать заголовки:**
```bash
curl -Li https://example.com
```

---
## 4. Работа с методами HTTP

**POST с данными формы (x-www-form-urlencoded):**
```bash
curl -X POST -d "username=ivan&password=123" https://example.com/login
```

**POST с JSON-данными:**
```bash
curl -X POST -H "Content-Type: application/json" -d '{"name":"Ivan","age":30}' https://api.example.com/users
```

**PUT (обновление ресурса):**
```bash
curl -X PUT -H "Content-Type: application/json" -d '{"status":"active"}' https://api.example.com/users/123
```

**DELETE:**
```bash
curl -X DELETE https://api.example.com/users/123
```

---
## 5. Отправка файлов (multipart/form-data)

**Загрузить файл:**
```bash
curl -F "file=@/path/to/document.pdf" https://upload.example.com/upload
```

**Отправить текстовое поле и файл одновременно:**
```bash
curl -F "user=ivan" -F "avatar=@photo.jpg" https://example.com/profile
```

---
## 6. Заголовки и аутентификация

**Добавить авторизационный заголовок (токен Bearer):**
```bash
curl -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." https://api.example.com/protected
```

**Базовая аутентификация (user:pass):**
```bash
curl -u admin:secret https://example.com/admin
```

**Указать несколько заголовков:**
```bash
curl -H "Accept: application/json" -H "X-API-Key: 12345" https://api.example.com/data
```

---
## 7. Работа с Cookies

**Сохранить cookies из ответа:**
```bash
curl -c cookies.txt https://example.com/login -d "user=ivan&pass=123"
```

**Использовать сохранённые cookies для последующих запросов:**
```bash
curl -b cookies.txt https://example.com/dashboard
```

---
## 8. Диагностика и отладка

**Показать подробный обмен (заголовки и тело):**
```bash
curl -v https://example.com
```

**Показать только заголовки запроса и ответа, без тела:**
```bash
curl -v -s -o /dev/null https://example.com
```

**Показать время выполнения запроса (разбивка по этапам):**
```bash
curl -w "%{time_total}\n" -o /dev/null -s https://example.com
```

---
## 9. Другие полезные опции

**Ограничить скорость скачивания:**
```bash
curl --limit-rate 100K -O https://example.com/bigfile.iso
```

**Продолжить прерванную загрузку:**
```bash
curl -C - -O https://example.com/bigfile.iso
```

**Таймаут на подключение и передачу данных:**
```bash
curl --connect-timeout 5 --max-time 30 https://example.com
```

**Игнорировать проверку SSL (для тестовых серверов с самоподписанными сертификатами):**
```bash
curl -k https://self-signed.badssl.com
```

---
## 10. Шпаргалка (самое частое)

```bash
# GET
curl https://api.example.com/items

# GET с заголовком
curl -H "Authorization: Bearer TOKEN" https://api.example.com/items

# POST JSON
curl -X POST -H "Content-Type: application/json" -d '{"key":"value"}' https://api.example.com/items

# POST форма
curl -X POST -d "key=value" https://api.example.com/items

# Скачать файл
curl -O https://example.com/file.zip

# Скачать с другим именем
curl -o myfile.zip https://example.com/file.zip

# Загрузить файл
curl -F "file=@photo.jpg" https://upload.example.com/upload

# Показать заголовки ответа
curl -I https://example.com

# Следовать редиректам
curl -L https://short.link/redirect

# Отладка
curl -v https://api.example.com

# Продолжить докачку
curl -C - -O https://example.com/largefile.iso
```

---
## 11. Частые ошибки и советы

- **Ошибка SSL:** используйте `-k` для тестовых сертификатов (никогда в продакшене).
- **Проблемы с кодировкой:** добавьте `-H "Content-Type: application/json; charset=utf-8"`.
- **Спецсимволы в данных:** экранируйте кавычки внутри JSON: `'{"name":"Ivan"}'` или используйте данные из файла: `-d @data.json`.
- **Сохранение вывода:** всегда перенаправляйте вывод в файл или в `/dev/null`, если не нужен.
- **Проверка доступности:** `curl -Is https://example.com | head -n1` — показать только статус-код.

`curl` — это универсальный клиент для взаимодействия с веб-сервисами. Освойте эти основы, и вы сможете быстро тестировать API, скачивать обновления, загружать логи и автоматизировать множество сетевых задач.
