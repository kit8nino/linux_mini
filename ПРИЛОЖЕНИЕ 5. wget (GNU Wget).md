
`wget` — это мощная консольная утилита для неинтерактивного скачивания файлов по протоколам HTTP, HTTPS и FTP. В отличие от `curl`, `wget` ориентирован на скачивание и рекурсивное зеркалирование, обладает встроенным механизмом возобновления прерванных загрузок и поддержкой рекурсивного обхода сайтов. Незаменим при скачивании больших файлов, бэкапов и синхронизации.

---
## 1. Базовый синтаксис

```bash
wget [опции] URL
```

- По умолчанию `wget` скачивает файл в текущую директорию и выводит прогресс-бар.
- Работает без интерактивного ввода (идеален для скриптов и cron).

---
## 2. Основные опции (самые частые)

| Опция | Действие |
| :--- | :--- |
| `-O файл` | Сохранить файл под указанным именем (или переопределить имя). |
| `-o logfile` | Записывать вывод (логи) в файл (не путать с `-O`). |
| `-q` | Тихий режим (без вывода на экран). |
| `-v` | Подробный вывод (verbose) — по умолчанию. |
| `-c` | Продолжить ранее прерванную загрузку (важно!). |
| `-b` | Запустить в фоновом режиме (с созданием `wget-log`). |
| `--limit-rate=100k` | Ограничить скорость загрузки (в байтах/сек). |
| `-t N` | Количество попыток при ошибке (по умолчанию 20). |
| `-T N` | Таймаут соединения (секунды). |
| `-i файл` | Прочитать список URL из файла. |
| `-P префикс` | Сохранять файлы в указанную директорию (префикс). |
| `-r` (--recursive) | Рекурсивное скачивание (для зеркалирования сайтов). |
| `-l глубина` | Глубина рекурсии (по умолчанию 5). |
| `-np` (--no-parent) | Не подниматься выше родительского каталога при рекурсии. |
| `-A` / `-R` | Принимать/отбрасывать файлы по расширениям. |
| `-H` (--span-hosts) | Разрешить переход на другие хосты при рекурсии. |
| `--no-check-certificate` | Игнорировать ошибки SSL-сертификата. |
| `--user=USER --password=PASS` | HTTP/аутентификация. |
| `--header="Заголовок: значение"` | Добавить заголовок. |
| `--post-data="данные"` | Отправить POST-запрос с данными. |

## 3. Базовые примеры

**Простое скачивание файла:**
```bash
wget https://example.com/file.zip
```

**Скачивание с указанием имени файла:**
```bash
wget -O myfile.zip https://example.com/file.zip
```

**Скачивание в другую папку:**
```bash
wget -P /target/dir/ https://example.com/file.zip
```

**Продолжить прерванную загрузку:**
```bash
wget -c https://example.com/largefile.iso
```

**Скачивание списка URL из файла (построчно):**
```bash
wget -i urls.txt
```

**Ограничение скорости (например, 100 КБ/с):**
```bash
wget --limit-rate=100k https://example.com/bigfile.zip
```

**Скачивание с авторизацией (Basic Auth):**
```bash
wget --user=admin --password=secret https://example.com/private/
```

**Игнорирование проверки SSL (для тестовых серверов):**
```bash
wget --no-check-certificate https://self-signed.badssl.com
```

## 4. Рекурсивное скачивание (зеркалирование)

**Рекурсивно скачать сайт (зеркало), следуя ссылкам:**
```bash
wget -r https://example.com
```

**Ограничить глубину рекурсии (например, 2 уровня):**
```bash
wget -r -l 2 https://example.com
```

**Не подниматься выше родительского каталога:**
```bash
wget -r -np https://example.com/docs/
```

**Принимать только определённые расширения (например, .html, .pdf):**
```bash
wget -r -A "*.html,*.pdf" https://example.com
```

**Игнорировать определённые расширения (например, .jpg, .png):**
```bash
wget -r -R "*.jpg,*.png" https://example.com
```

**Зеркалирование с сохранением структуры каталогов и преобразованием ссылок для локального просмотра:**
```bash
wget -mk -np https://example.com
```
- `-m` (--mirror) — включает `-r`, `-N`, `-l inf`, `--no-remove-listing`.
- `-k` (--convert-links) — преобразует ссылки в локальные для просмотра офлайн.
- `-np` — не подниматься выше.

**Ограничить переход на другие хосты (только текущий домен):**
```bash
wget -r -np -H https://example.com
```
`-H` разрешает переход на другие хосты, но без него `wget` не выходит за пределы указанного хоста.

---
## 5. Фоновый режим и логирование

**Запуск в фоне:**
```bash
wget -b https://example.com/bigfile.zip
# Лог пишется в wget-log (по умолчанию)
```

**Писать лог в отдельный файл:**
```bash
wget -o download.log https://example.com/file.zip
```

**Тихий режим (никакого вывода на экран):**
```bash
wget -q https://example.com/file.zip
```

---
## 6. Продвинутые примеры

**Скачивание с использованием таймаута и повторных попыток:**
```bash
wget --connect-timeout=10 --tries=5 https://example.com/file
```

**Загрузка файла по FTP с аутентификацией:**
```bash
wget ftp://user:pass@ftp.example.com/file.txt
```

**Загрузка файла с указанием User-Agent (чтобы обойти ограничения):**
```bash
wget --user-agent="Mozilla/5.0" https://example.com
```

**Отправка POST-запроса (например, для API):**
```bash
wget --post-data="param1=value1&param2=value2" https://example.com/api
```

**Скачивание файлов, указанных в файле, с ограничением скорости:**
```bash
wget -i urls.txt --limit-rate=500k
```

## 7. Шпаргалка (самое частое)

```bash
# Скачать файл
wget https://example.com/file.zip

# Сохранить с другим именем
wget -O myfile.zip https://example.com/file.zip

# Продолжить докачку
wget -c https://example.com/largefile.iso

# Рекурсивно скачать сайт (зеркало)
wget -r https://example.com

# Рекурсивно скачать с ограничением глубины и без подъёма выше
wget -r -l 3 -np https://example.com/docs/

# Зеркалирование с преобразованием ссылок (для локального просмотра)
wget -mk https://example.com

# Ограничить скорость (100 КБ/с)
wget --limit-rate=100k https://example.com/bigfile

# Скачать список URL из файла
wget -i urls.txt

# Скачать с Basic Auth
wget --user=user --password=pass https://example.com/private

# Игнорировать SSL (для самоподписанных сертификатов)
wget --no-check-certificate https://example.com

# Тихий режим, запись лога в файл
wget -q -o log.txt https://example.com/file.zip
```

---
## 9. Полезные советы

- **Используйте `-c` при повторных загрузках**, чтобы избежать скачивания заново.
- **Для массовой загрузки** используйте `-i` с файлом URL.
- **В фоновом режиме** (`-b`) лог записывается в `wget-log`, его можно отслеживать через `tail -f wget-log`.
- **Ограничивайте скорость** при работе с ограниченными каналами, чтобы не забить весь трафик.
- **При зеркалировании** используйте `--convert-links` для локального просмотра.
- **Не забудьте про `--no-check-certificate`**, если работаете с самоподписанными сертификатами в тестовой среде.

---

`wget` — это надёжный инструмент для скачивания, который спасает при работе с большими файлами и создании локальных копий сайтов. Освойте его — и вы всегда сможете быстро получить нужные данные. 
`wget` — идеален для скачивания и зеркалирования, особенно для автоматических задач. `curl` — более универсален для взаимодействия с API и отладки.
