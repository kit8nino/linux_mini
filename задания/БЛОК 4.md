
## Задание 2. Арифметическая подстановка `$((...))` (4.1.2)

1. Базовые операции:
   ```bash
   x=10; y=3
   echo "Сумма: $((x + y))"
   echo "Разность: $((x - y))"
   echo "Умножение: $((x * y))"
   echo "Деление: $((x / y))"
   echo "Остаток: $((x % y))"
   echo "Степень: $((x ** 2))"
   ```
2. Инкремент и декремент:
   ```bash
   ((x++)); echo "x после x++: $x"
   ((x--)); echo "x после x--: $x"
   ```
3. Целочисленное деление:
   ```bash
   echo "10 / 3 = $((10 / 3))"
   echo "10 % 3 = $((10 % 3))"
   ```
4. Сравнение внутри арифметики:
   ```bash
   a=5; b=10
   (( a > b )) && echo "a > b" || echo "a <= b"
   ```
5. Использование в цикле:
   ```bash
   for ((i=1; i<=5; i++)); do
       echo "Итерация $i"
   done
   ```

**Проверка:** уметь считать сумму, остаток и работать с инкрементом.

## Задание 3. Подстановка переменных: модификаторы `${VAR...}` (4.1.3)

1. Значение по умолчанию:
   ```bash
   name=""
   echo "Привет, ${name:-гость}"
   unset name
   echo "Привет, ${name:-гость}"
   ```
2. Присвоение по умолчанию:
   ```bash
   unset log
   echo "${log:=/tmp/app.log}"
   echo "Теперь log=$log"
   ```
3. Замена подстроки:
   ```bash
   path="/home/user/file.txt"
   echo "${path/user/root}"
   echo "${path//o/0}"
   ```
4. Удаление префиксов и суффиксов:
   ```bash
   file="project/src/main.c"
   echo "Кратчайший префикс: ${file#*/}"
   echo "Длиннейший префикс: ${file##*/}"
   echo "Кратчайший суффикс: ${file%.*}"
   echo "Длиннейший суффикс: ${file%%.*}"
   ```
5. Длина строки:
   ```bash
   str="hello world"
   echo "Длина: ${#str}"
   ```
6. Переименование расширений:
   ```bash
   touch a.jpg b.jpg c.jpg
   for f in *.jpg; do mv "$f" "${f%.jpg}.jpeg"; done
   ls
   ```

**Проверка:** уметь использовать `:-`, `:=`, `/`, `//`, `#`, `##`, `%`, `%%`, `#VAR`.

## Задание 4. Brace expansion `{...}` и Wildcards (4.1.4–4.1.6)

1. Brace expansion:
   ```bash
   cd /tmp/block4
   touch file_{1..5}.txt
   ls file_*.txt
   mkdir -p project/{2023,2024,2025}/src
   tree project 2>/dev/null || find project -type d
   echo {a,b}{1,2}
   ```
2. Wildcards:
   ```bash
   touch file1.txt fileA.txt file10.txt
   ls file?.txt        # file1.txt, fileA.txt (не file10.txt)
   ls file*.txt        # все
   ls file[0-9].txt    # только с цифрой
   ```
3. Tilde expansion:
   ```bash
   echo ~
   echo ~root 2>/dev/null
   cd ~ && pwd
   ```

**Проверка:** понимать, что brace expansion работает до подстановки переменных, а wildcards — раскрытие имён файлов.

## Задание 7. Способы запуска команд (4.2)

1. **Синхронный запуск:** `sleep 2 && echo "done"`
2. **Фоновый запуск:**
   ```bash
   sleep 30 &
   jobs
   ```
3. **Логическое И / ИЛИ:**
   ```bash
   true && echo "OK"
   false || echo "FAIL"
   true && echo "yes" || echo "no"
   false && echo "yes" || echo "no"
   ```
4. **Последовательное выполнение:**
   ```bash
   echo "first" ; echo "second"
   ```
5. **`nohup`:**
   ```bash
   nohup sleep 5 &
   ls -l nohup.out 2>/dev/null
   ```
6. **`source` vs `./script.sh`:**
   ```bash
   cat > setvar.sh << 'EOF'
   #!/bin/bash
   MYVAR="hello"
   echo "Внутри скрипта: $MYVAR"
   EOF
   chmod +x setvar.sh
   ./setvar.sh
   echo "После ./: $MYVAR"    # пусто
   source setvar.sh
   echo "После source: $MYVAR"
   ```
7. **`eval`:**
   ```bash
   cmd="echo dynamic"
   eval "$cmd"
   ```
8. **`exec`** — только в отдельной оболочке:
   ```bash
   bash -c 'exec echo "заменяю оболочку"'
   echo "эта строка выполнится в родительской оболочке"
   ```
9. **`tmux`** (если установлен):
   ```bash
   tmux new -s test -d
   tmux ls
   tmux kill-session -t test
   ```

**Проверка:** уметь объяснить разницу между `&`, `nohup`, `source`, `eval`, `exec`.

## Задание 8. Принципы однострочников (4.3)

1. **UUOC:** уберите лишний `cat`:
   ```bash

   cat /etc/passwd | grep root
   # Хорошо:

   ```

   ```bash
   echo $(( $(cat /etc/hostname | wc -c) + 1 ))
   ```
3. **`xargs` с пробелами:**
   ```bash
   mkdir -p "dir with spaces"
   touch "dir with spaces/file one.txt"
   find . -name "*.txt" -print0 | xargs -0 ls -l
   ```
4. **`<<<` вместо `echo |`:**
   ```bash
   bc <<< "2^10"
   ```
5. **Логические операторы:**

6. **`find -exec +` вместо `\;`:**
   ```bash
   find . -name "*.txt" -exec grep -l "one" {} +
   ```
7. **Dry-run:**
   ```bash
   find /tmp/block4 -name "*.tmp" -print   # сначала посмотреть
   # find /tmp/block4 -name "*.tmp" -delete  # потом удалить
   ```
8. **Экранирование:**
   ```bash
   echo "192.168.1.1" | grep "192\.168\."
   sed 's#/tmp/block4#/tmp/block5#g' <<< "path: /tmp/block4/file"
   ```
