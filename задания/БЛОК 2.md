## Задание 1. Определение местоположения: `pwd` (2.1)

1. Откройте терминал и узнайте, где вы находитесь:
   ```bash
   pwd
   ```
2. Убедитесь, что `$PWD` совпадает с выводом `pwd`:
   ```bash
   echo $PWD
   ```
3. Перейдите в `/etc` и снова проверьте `pwd` и `$PWD`:
   ```bash
   cd /etc
   pwd
   echo $PWD
   ```
4. Вернитесь в домашнюю папку и посмотрите, как меняется `$PWD`:
   ```bash
   cd ~
   pwd
   ```

**Проверка:** объясните, зачем нужна `$PWD` в скриптах.

## Задание 2. Инспекция содержимого: `ls` (2.2)

1. Создайте песочницу и файлы:
   ```bash
   mkdir -p /tmp/block2 && cd /tmp/block2

   ```

   ```bash
   alias ll='ls -alh'
   ll
   ```

**Проверка:** уметь объяснить, что делает каждый флаг и как читать первую строку `ls -l`.

## Задание 3. Перемещение между папками: `cd` (2.3)

1. Перейдите по абсолютному пути:
   ```bash
   cd /var/log
   pwd
   ```
2. Перейдите по относительному пути:
   ```bash
   cd ..
   pwd
   cd log
   pwd
   ```
3. Используйте спецсимволы:
   ```bash
   cd ~
   cd -
   cd -
   cd .
   pwd
   ```
4. Проверьте автодополнение:
   ```bash
   cd /v<Tab>
   cd /var/lo<Tab>
   ```
5. Настройте `CDPATH` и проверьте работу:
   ```bash
   mkdir -p ~/Projects/test_cdpath
   export CDPATH=.:~:~/Projects:/var/lib
   cd test_cdpath
   pwd
   ```
6. Верните `CDPATH` (или откройте новый терминал):
   ```bash
   unset CDPATH
   ```

**Проверка:** понимать разницу между абсолютным и относительным путём, уметь пользоваться `cd -` и `CDPATH`.

## Задание 4. Поиск файлов: `find` (2.4)

1. Подготовьте структуру:
   ```bash
   mkdir -p /tmp/block2/find_test/logs
   cd /tmp/block2/find_test
   touch app.log error.log old.log
   touch /tmp/block2/find_test/logs/nginx.conf
   touch empty.tmp
   dd if=/dev/zero of=big.bin bs=1M count=5 2>/dev/null
   ```
2. Поиск по имени:
   ```bash
   find . -name "*.log"
   find . -iname "NGINX.CONF"
   ```
3. Поиск по типу:
   ```bash
   find . -type f
   find . -type d
   ```
4. Поиск по размеру:
   ```bash
   find . -size +1M
   find . -size 0
   ```
5. Поиск по времени:
   ```bash
   find . -mtime -1
   find . -mmin -10
   ```
6. Действие `-exec`:
   ```bash
   find . -name "*.log" -exec chmod 644 {} \;
   find . -name "*.log" -exec ls -l {} +
   ```
7. Опасный `-delete` — сначала проверьте без него:
   ```bash
   find . -name "*.tmp"
   find . -name "*.tmp" -delete
   find . -name "*.tmp"
   ```

**Проверка:** уметь комбинировать критерии (`-name`, `-type`, `-size`, `-mtime`) и безопасно использовать `-exec` и `-delete`.

## Задание 10. Комплексный мини-проект (2.1–2.9)

   ```bash
   mkdir -p /tmp/block2_project/{logs,configs,data}

   ```


   ```bash

   find . -name "*.log" -exec chmod 644 {} \;
   ```

   ```bash
   find . -size +1M
   ```

   ```bash
   du -sh * | sort -hr
   ```

   ```bash
   find . -type f -exec file {} \;
   ```

   ```bash
   cd /
   rm -rf /tmp/block2_project /tmp/block2
   ```
