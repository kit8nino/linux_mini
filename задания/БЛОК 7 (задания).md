## Общие требования к раннеру (для всех задач)

- Массив тест-кейсов в формате `"аргументы... ожидаемый_результат"`.
- Проверка существования и исполняемости целевого скрипта.
- Захват вывода через `$(...)`, унификация ошибок через `|| actual="ERROR"`.
- Счётчики `pass`/`fail`, `exit 1` при `fail > 0`.
- Понятный вывод: `PASS: <кейс>` / `FAIL: <кейс> (получено: <actual>)`.

**Общий паттерн:** `run_tests.sh` вызывает другой скрипт (`target.sh`) с разными параметрами, сравнивает фактический вывод и код возврата с ожидаемыми, считает PASS/FAIL, возвращает `exit 1` при наличии провалов.

## 1. Тестирование валидатора email

**Задача:** написать `run_tests.sh`, который проверяет скрипт `validate_email.sh`. Тот принимает email и возвращает `VALID` или `INVALID` (код 0/1). Прогнать кейсы: корректные адреса, без `@`, без домена, с пробелами, с несколькими `@`. Проверить и вывод, и код возврата.

---

## 2. Тестирование конвертера температур

**Задача:** написать раннер для `convert_temp.sh`, который принимает `C→F` или `F→C` и число. Тест-кейсы: `C→F 0 → 32`, `C→F 100 → 212`, `F→C 32 → 0`, некорректная единица измерения → `ERROR`. Сравнить точность до одного знака после запятой.

---

## 3. Тестирование калькулятора скидок

**Задача:** написать раннер для `discount.sh`, который принимает цену и процент скидки. Тест-кейсы: обычная скидка, скидка 0%, скидка 100%, отрицательная цена → ошибка, процент > 100 → ошибка. Проверить, что результат совпадает с ожидаемым с точностью до копеек.

---

## 4. Тестирование парсера логов

**Задача:** написать раннер для `parse_log.sh`, который принимает строку лога и возвращает IP-адрес. Тест-кейсы: стандартная строка, строка без IP, строка с двумя IP, пустая строка. Проверить, что скрипт корректно извлекает поле и обрабатывает ошибки.

---

## 5. Тестирование проверки пароля

**Задача:** написать раннер для `check_password.sh`, который принимает пароль и возвращает `STRONG`/`WEAK` по правилам: длина ≥ 8, есть цифра, есть заглавная, есть спецсимвол. Тест-кейсы: все правила выполнены, каждое правило нарушено по отдельности, пароль пустой.

---

## 6. Тестирование генератора конфига

**Задача:** написать раннер для `gen_config.sh`, который принимает имя хоста и порт и подставляет их в шаблон `template.conf` через `sed`. Тест-кейсы: обычные значения, порт вне диапазона, пустой хост. Проверить, что итоговый файл содержит правильные подстановки и не содержит плейсхолдеров.

---

## 7. Тестирование конвертера дат

**Задача:** написать раннер для `convert_date.sh`, который принимает дату в формате `YYYY-MM-DD` и возвращает `DD/MM/YYYY`. Тест-кейсы: обычная дата, 29 февраля високосного года, невалидный день (32), невалидный месяц (13), неверный формат. Проверить и вывод, и код возврата.

---

## 8. Тестирование проверки URL

**Задача:** написать раннер для `check_url.sh`, который принимает URL и возвращает HTTP-статус. Тест-кейсы: доступный URL, недоступный URL, неверный формат URL, пустая строка. Для тестов использовать локальный `nc`-слушатель или заранее известные URL.

## 9. Тестирование обработчика CSV

**Задача:** написать раннер для `filter_csv.sh`, который принимает CSV-файл и значение колонки, возвращает строки, где колонка совпадает. Тест-кейсы: есть совпадения, нет совпадений, пустой файл, неверное число колонок. Проверить, что вывод совпадает построчно.

## 10. Тестирование сортировщика файлов

**Задача:** написать раннер для `sort_files.sh`, который принимает папку и раскладывает файлы по подпапкам в зависимости от расширения. Тест-кейсы: файлы разных расширений, файлы без расширения, пустая папка, несуществующая папка. Проверить структуру каталогов после запуска.

## 11. Тестирование проверки прав доступа

**Задача:** написать раннер для `check_perms.sh`, который принимает файл и возвращает строку вида `rwx` или `r--` для владельца. Тест-кейсы: файл с правами 755, 644, 600, 000, несуществующий файл. Проверить соответствие вывода и кода возврата.

---

## 12. Тестирование сумматора чисел

**Задача:** написать раннер для `sum_numbers.sh`, который принимает список чисел через аргументы и возвращает их сумму. Тест-кейсы: положительные числа, отрицательные, ноль, пустой список → ошибка, нечисловой аргумент → ошибка. Проверить и сумму, и обработку граничных случаев.
