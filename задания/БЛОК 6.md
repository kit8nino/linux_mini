## Задание 11. Комплексный мини-проект (6.1–6.13)

Напишите скрипт `monitor_dir.sh`, который:
1. Принимает один аргумент — путь к папке.
2. Проверяет, что аргумент передан и папка существует.
3. Создаёт лог `/tmp/block6/monitor.log`.
4. Логирует начало и конец работы с временными метками.
5. Считает количество файлов и папок в указанной директории.
6. Считает суммарный размер в КБ.
7. Если размер больше 100 КБ — пишет предупреждение.
8. Использует функции для логирования и проверок.
9. Использует `set -euo pipefail` и `trap` для очистки временного файла.
10. Возвращает код 0 при успехе и 1 при ошибке.

**Подсказка-каркас:**
```bash
#!/bin/bash
set -euo pipefail
LOG="/tmp/block6/monitor.log"
TEMP=$(mktemp)
trap 'rm -f "$TEMP"' EXIT

log() {
    echo "[$(date '+%F %T')] $*" | tee -a "$LOG"
}

if [ $# -ne 1 ]; then
    echo "Использование: $0 <папка>" >&2
    exit 1
fi

DIR="$1"
[ -d "$DIR" ] || { echo "Не папка: $DIR" >&2; exit 1; }

log "Старт: $DIR"
FILES=$(find "$DIR" -type f | wc -l)
DIRS=$(find "$DIR" -type d | wc -l)
SIZE=$(du -sk "$DIR" | awk '{print $1}')
log "Файлов: $FILES, папок: $DIRS, размер: ${SIZE}K"
if [ "$SIZE" -gt 100 ]; then
    log "ПРЕДУПРЕЖДЕНИЕ: размер > 100K"
fi
log "Готово"
```

**Проверка:** запустите с `bash -x monitor_dir.sh /etc`, затем проверьте лог. Запустите без аргумента и с несуществующей папкой — должны быть корректные ошибки.
