## Задание 1. Ядро и оболочка (1.1)

1. Узнайте версию ядра и архитектуру:
   ```bash
   uname -a
   ```
2. Найдите, где лежит Bash, и какая оболочка у вас сейчас:
   ```bash
   which bash
   echo $SHELL
   ```
3. Запустите вложенную оболочку и выйдите из неё:
   ```bash
   bash
   echo $0
   exit
   ```

## Задание 2. «Всё есть файл» и FHS (1.2)

1. Осмотрите корень и ключевые каталоги:
   ```bash
   ls -la /
   ls -la /home /etc /var/log /tmp /dev /proc
   ```
2. Найдите устройства в `/dev`:
   ```bash
   ls -l /dev | head
   ls -l /dev/null /dev/tty
   ```
3. Проверьте «чёрную дыру»:
   ```bash
   echo "test" > /dev/null
   cat /dev/null
   ls -l /dev/null
   ```
   
   4. Прочитайте информацию о процессоре через `/proc`:
   ```bash
   cat /proc/cpuinfo | grep "model name" | head -1
   ```

**Проверка:** объясните, почему диск, процесс и лог — это всё «файлы».

## Задание 3. Права доступа: чтение и `chmod` (1.3)

1. Создайте песочницу:
   ```bash
   mkdir -p /tmp/block1 && cd /tmp/block1
   touch file.txt
   echo "hello" > file.txt
   ls -l file.txt
   ```
2. Расшифруйте вывод `-rw-r--r--`: где владелец, группа, остальные.
3. Поменяйте права и каждый раз смотрите результат:
   ```bash
   chmod 600 file.txt; ls -l file.txt
   chmod 640 file.txt; ls -l file.txt
   chmod 644 file.txt; ls -l file.txt
   chmod 755 file.txt; ls -l file.txt
   ```
4. Поработайте с папкой:
   ```bash
   mkdir dir
   chmod 700 dir
   ls -ld dir
   touch dir/inside
   chmod 500 dir
   touch dir/new_file   # должно быть Permission denied
   chmod 700 dir
   ```
5. Уберите право чтения для остальных:
   ```bash
   chmod o-r file.txt
   ls -l file.txt
   ```

**Проверка:** уметь считать права в цифрах и объяснять `r/w/x` для файла и папки.

## Задание 4. Владелец и группа: `chown` (1.3)

1. Посмотрите текущего владельца:
   ```bash
   cd /tmp/block1
   ls -l file.txt
   ```
2. Смените владельца и группу (если есть `nobody`/`nogroup`):
   ```bash
   sudo chown nobody:nogroup file.txt
   ls -l file.txt
   ```
3. Верните владельца себе:
   ```bash
   sudo chown $USER:$USER file.txt
   ls -l file.txt
   ```
4. Рекурсивная смена владельца:
   ```bash
   mkdir -p dir2/sub
   touch dir2/sub/a
   sudo chown -R nobody:nogroup dir2
   ls -lR dir2
   ```
5. Смена владельца по образцу:
   ```bash
   touch ref
   chmod 600 ref
   sudo chown --reference=ref file.txt
   ls -l file.txt ref
   ```

**Проверка:** уметь менять владельца/группу, рекурсивно и по reference-файлу.

## Задание 5. Потоки: `>`, `>>`, `2>`, `2>&1`, `/dev/null` (1.4)

1. Перенаправьте STDOUT в файл:
   ```bash
   cd /tmp/block1
   ls /etc > out.txt
   head out.txt
   ```
2. Перенаправьте STDERR в отдельный файл:
   ```bash
   ls /nonexistent 2> err.txt
   cat err.txt
   ```
3. Разделите потоки:
   ```bash
   ls /etc /nonexistent > out2.txt 2> err2.txt
   cat out2.txt
   cat err2.txt
   ```
4. Объедините потоки:
   ```bash
   ls /etc /nonexistent > all.txt 2>&1
   cat all.txt
   ```
5. Добавьте строку в конец файла:
   ```bash
   echo "append" >> all.txt
   tail -n1 all.txt
   ```
6. Отправьте ошибки в никуда:
   ```bash
   ls /nonexistent 2>/dev/null
   echo $?
   ```

**Проверка:** объяснить, чем `>` отличается от `>>`, и что делает `2>&1`.

## Задание 6. Комплексный мини-проект (1.1–1.5)

1. Создайте проектную папку:
   ```bash
   mkdir -p /tmp/block1_project && cd /tmp/block1_project
   ```
2. Создайте защищённый файл:
   ```bash
   echo "secret" > secret.txt
   chmod 600 secret.txt
   ```
3. Создайте общую папку:
   ```bash
   mkdir shared
   echo "public" > shared/public.txt
   chmod 755 shared
   chmod 644 shared/public.txt
   ```
4. Посмотрите права:
   ```bash
   ls -la
   ls -l shared
   ```
5. Соберите листинг и ошибки:
   ```bash
   ls -la > listing.txt 2> listing.err
   ```
6. Сохраните информацию о CPU:
   ```bash
   cat /proc/cpuinfo | grep "model name" | head -1 > cpu.txt
   ```
7. Добавьте ошибку в лог ошибок:
   ```bash
   ls /nonexistent 2>> listing.err
   cat listing.err
   ```
8. Если можно, смените владельца папки `shared`:
   ```bash
   sudo chown -R nobody:nogroup shared
   ls -l shared/public.txt
   ```
9. Уберите за собой только свои временные папки:
   ```bash
   cd /
   rm -rf /tmp/block1_project /tmp/block1
   ```

**Проверка:** вы объединили FHS, права, `chown` и перенаправления потоков.
