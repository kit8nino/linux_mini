# Общие правила для обоих заданий

1. **Пишите команды по одной.** После каждого шага запускайте и смотрите результат.
2. **Не пытайтесь сразу написать финальный однострочник.** Соберите его из проверенных кусочков.
3. **Если что-то не работает** — уберите последний добавленный элемент и проверьте предыдущий.
4. **Когда однострочник готов** — сохраните его в файл `~/one-liners.md` с кратким комментарием.
5. **Проверяйте на изменённых данных.** Удалили файл, добавили строки — однострочник должен корректно отработать.
