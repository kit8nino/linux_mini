## Задание 12. Комплексный мини-проект (7.1–7.5)

Соберите всё вместе в `supervisor.sh`:

1. Принимает аргумент `--status` (только проверка) или работает в обычном режиме.
2. Имеет массив `SERVICES` и ассоциативный массив `SERVICE_PORTS`.
3. Функция `log` пишет в `/tmp/block7/supervisor.log` с временной меткой.
4. Функция `check_process` проверяет `pgrep -x`.
5. Функция `check_port` проверяет `nc -z`.
6. Функция `restart_service` пытается перезапустить до 3 раз, замеряет время.
7. Функция `get_system_stats` собирает load average и память.
8. Основной цикл проходит по сервисам, при сбое — перезапускает (если не `--status`).
9. В конце — итог: сколько сервисов в норме, сколько сбоев, время работы.
10. Использует `set -euo pipefail` и `trap` для очистки временного файла.

**Каркас:**
```bash
#!/bin/bash
set -euo pipefail
LOG="/tmp/block7/supervisor.log"
TEMP=$(mktemp)
trap 'rm -f "$TEMP"' EXIT

SERVICES=("svc1" "svc2" "svc3")
declare -A SERVICE_PORTS=([svc1]=8001 [svc2]=8002 [svc3]=8003)

log() { echo "[$(date '+%F %T')] $*" | tee -a "$LOG"; }

check_process() { pgrep -x "$1" >/dev/null 2>&1; }
check_port()    { nc -z 127.0.0.1 "$2" 2>/dev/null; }

restart_service() {
    local svc="$1" attempts=3
    for ((i=1; i<=attempts; i++)); do
        log "Попытка $i: перезапуск $svc"
        systemctl restart "$svc" 2>/dev/null && return 0
        sleep 2
    done
    return 1
}

get_system_stats() {
    local load=$(uptime | awk -F'load average:' '{print $2}' | cut -d',' -f1 | xargs)
    local mem=$(free -m | awk '/Mem:/ {print $3"/"$2"MB"}')
    echo "CPU: $load, RAM: $mem"
}

MODE="${1-}"
log "======= СТАРТ ($MODE) ======="
log "Система: $(get_system_stats)"

ok=0; fail=0
for svc in "${SERVICES[@]}"; do
    if check_process "$svc"; then
        log "$svc: OK (process)"
        ((ok++))
    elif check_port "$svc" "${SERVICE_PORTS[$svc]}"; then
        log "$svc: OK (port)"
        ((ok++))
    else
        log "$svc: FAIL"
        if [ "$MODE" != "--status" ]; then
            start=$(date +%s)
            restart_service "$svc" && log "$svc перезапущен за $(( $(date +%s) - start ))с" || log "$svc не удалось перезапустить"
        fi
        ((fail++))
    fi
done

log "Итог: OK=$ok, FAIL=$fail"
log "======= КОНЕЦ ======="
```

**Проверка:** запустите с `--status` и без, смоделируйте сбой, проверьте лог.
