## 2.1. Определение местоположения: `pwd` (Print Working Directory)

Это первая команда, которую вы должны вбить, зайдя на незнакомый сервер. Она показывает ваш текущий абсолютный путь в файловой системе.

```bash
pwd
# Вывод: /home/ivan/projects
```

**Важно:** В Bash текущая директория хранится в переменной окружения `$PWD`. Можете убедиться: `echo $PWD`. Когда вы пишете скрипты, всегда используйте `$PWD`, если нужно вернуться назад, но помните, что если скрипт переходит по `cd`, значение `$PWD` меняется.

## 2.2. Инспекция содержимого: `ls` (List Directory Contents)

Это ваши глаза. Бездумное использование `ls` — моветон. Используйте комбинации флагов, чтобы видеть суть.

**Базовые флаги (обязательные к запоминанию):**

| Флаг | Расшифровка | Что делает | Пример |
| :--- | :--- | :--- | :--- |
| `-l` | Long | Подробный список (права, владелец, размер, дата). | `ls -l` |
| `-a` | All | Показывать всё, включая скрытые файлы (начинающиеся с `.`). | `ls -la` |
| `-h` | Human-readable | Размер файлов в КБ, МБ, ГБ (а не в байтах). | `ls -lh` |
| `-t` | Time | Сортировать по времени изменения (свежие сверху). | `ls -lt` |
| `-r` | Reverse | Обратный порядок сортировки. | `ls -ltr` (старые файлы сверху) |
| `-S` | Size | Сортировать по размеру (большие сверху). | `ls -lS` |

**Золотой стандарт (алиас, который я ставлю первым делом):**
`alias ll='ls -alh'` — выводит ВСЁ, с правами, понятными размерами.

**Как читать цвета (или символы, если цвета нет):**

- `/` — папка (Directory).
- `*` — исполняемый файл (Executable).
- `@` — символическая ссылка (Link).
- `=` — сокет (Socket).

**Совет:** Если в папке 1000 файлов, никогда не делайте просто `ls`. Сервер начнет ворочать этот список, и вы замерзнете. Используйте `ls | head -20` (первые 20) или `ls -l | tail -10` (последние 10).

## 2.3. Перемещение между папками: `cd` (Change Directory)

Навигация — это мышцы. Вы должны делать это на рефлексах.

**Абсолютный vs Относительный путь:**

- **Абсолютный:** Начинается с `/` (корня). Всегда точен. *Пример:* `cd /var/log/nginx`.
- **Относительный:** Начинается с имени папки или спецсимволов. Зависит от того, где вы сейчас.
  - `.` — текущая папка (почти никогда не используется отдельно, но нужна в скриптах).
  - `..` — родительская папка (на уровень выше).
  - `~` — домашняя папка текущего пользователя.
  - `-` — предыдущая папка (ВОЛШЕБНАЯ фишка!).

```bash
# ВЫ были в /home/user
cd /etc           # Перешли в /etc
cd ~              # Вернулись в /home/user
cd -              # Вернулись обратно в /etc (бесплатный "назад")
```

**Лайфхак для быстрой печати:** Нажимайте `Tab` для автодополнения. Пишите `cd /v` + `Tab` → `/var/`. Не печатайте длинные имена вручную.

**CDPATH** — это переменная окружения, которая работает только с командой `cd`. Она содержит список каталогов, разделённых двоеточием. Полезно внести в нее основной рабочий каталог и каталог уровня выше (..).
```bash
# добавить в переменную окружения рабочие папки и папку ..
# от порядка перечисления зависит порядок поиска, перейдет в первую найденную
CDPATH=.:..:~/Documents:~/Projects:/var/lib:/usr/share:/opt

```

## 2.4. Поиск файлов: `find` (Ваше главное оружие)

`grep` ищет *внутри* файлов, а `find` ищет *сами* файлы по атрибутам. Эту команду вы будете использовать каждый день для чистки мусора и поиска конфигов.

**Синтаксис:** `find [ГДЕ ИСКАТЬ] [КРИТЕРИЙ] [ДЕЙСТВИЕ]`

**Самые частые критерии:**

1.  **По имени (маска):**
    `find /var/log -name "*.log"` — найти все логи.
    `find . -iname "nginx.conf"` — `-iname` игнорирует регистр (NGINX.conf).

2.  **По типу:**
    `find /home -type f` — только файлы.
    `find /home -type d` — только папки.

3.  **По размеру:**
    `find / -size +100M` — найти файлы больше 100 мегабайт (отлично для поиска мусора).
    `find . -size 0` — найти пустые файлы (часто мешают).

4.  **По времени:**
    `find . -mtime -7` — файлы, измененные *менее* 7 дней назад.
    `find . -mtime +30` — файлы, измененные *более* 30 дней назад (кандидаты на удаление).
    `find . -mmin -10` — файлы, измененные за последние 10 минут.

**Самое опасное и полезное — ДЕЙСТВИЕ:**

*   `-delete` — удалить найденное. *Осторожно! Сначала запустите без delete, чтобы проверить.*
    `find /tmp -name "*.tmp" -delete` — убить все временные файлы.

*   `-exec` — выполнить команду для каждого найденного файла.
    `find . -name "*.jpg" -exec mv {} ./images/ \;` — переместить все jpg в папку images.
    `find . -name "*.txt" -exec chmod 644 {} \;` — поправить права на всех текстовых файлах.

**Внимание (Важно!):** Вместо `{}` подставляется имя найденного файла. `\;` — говорит `find`, что команда `-exec` закончена.

## 2.5. Анализ дискового пространства: `du` и `df`

Сервер упал? Закончилось место. Это первое, что следует проверить.

**`df -h` (Disk Free)** — смотрим, сколько осталось на разделах (дисках) целиком.
*Вывод:* `Filesystem Size Used Avail Use% Mounted on`
Видим, что `/dev/sda1` забит на 95% — аларм.

**`du -sh *` (Disk Usage)** — смотрим, сколько весит каждая папка *внутри* текущей.
*   `-s` (summary) — не перечислять файлы внутри, только итог по папке.
*   `-h` (human-readable) — в МБ/ГБ.

**Боевой пример (найти чемпиона по весу):**
`du -sh /home/* | sort -hr` — показать вес всех папок в `/home/` и отсортировать по убыванию (самая жирная сверху).

## 2.6. Быстрый просмотр типа файла: `file`

Вы скачали файл, но не знаете, что внутри? Может, это текстовый конфиг, а может, бинарник или архив. `cat` на бинарнике засрет экран.
Используйте `file`:

```bash
file unknown_file
# Вывод: unknown_file: ASCII text (если текст)
# Вывод: unknown_file: gzip compressed data (если архив)
```

## 2.7. Магия истории (Скорость работы)

Не перепечатывайте длинные команды! Используйте историю.

*   **`history`** — показать весь список ранее введенных команд с номерами.
*   **`!100`** — выполнить команду под номером 100 из истории.
*   **`!!`** — выполнить *последнюю* команду.
*   **`Ctrl + R`** — **Reverse Search** (Самый важный навык!). Нажимаете, начинаете печатать кусок команды (например, "nginx"), и Bash показывает последнюю команду, где это было. Нажмите `Enter` — выполнится, нажмите `Ctrl+R` еще раз — покажет предыдущее совпадение.
*   **Очистка истории:** Если вы ввели пароль в открытую, поставьте пробел перед командой в следующий раз — ` history` (с пробелом) не сохранится.

## 2.9. Шпаргалка по «Боевым связкам» (Комбинации)

Одиночные команды хороши, но цепочки спасают жизнь.

| Задача                                                                                                 | Команда (пайп + комбинация)                                           |
| :----------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------- |
| **Найти 5 самых больших файлов в /var**                                                                | ` find /var -type f -exec du -h {} + `\|` sort -hr `\|` head -5`      |
| **Подсчитать количество файлов в папке**                                                               | `ls -1 `\|` wc -l ` (где `wc -l` считает строки)                      |
| **Узнать свой IP по внешнему интерфейсу**                                                              | `curl -s ifconfig.me` (если есть интернет)                            |
| **Посмотреть последних залогинившихся**                                                                | `last -n 5`                                                           |
| **Найти все процессы с определенным именем и убить по PID** (аналогично можно сделать через `killall`) | ` ps aux `\|` grep "my_app" `\|` awk '{print $2}' `\|` xargs kill -9` |
| **Посмотреть, какой процесс слушает порт 8080**                                                        | `netstat -tulpn `\|` grep :8080` (или `ss -tulpn `\|` grep :8080`).   |

Не храните важные файлы в корне `/`. Не ходите по серверу под `root` (используйте `sudo`). Если вы не знаете, куда идете, сначала сделайте `ls -la` и прочитайте `README.md` (если есть).
